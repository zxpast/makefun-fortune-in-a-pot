## The entry

> In three weeks the sun will file a formal complaint: you have hogged the whole windowsill since October.

104 characters. A dated prediction about the plant's own future: the sun files a formal complaint because the plant has hogged the whole windowsill since October. The plant is the active winner of the light, and the twist lands in the last words.

## How it works

`main.ts` (Node 22, stdlib only) writes the line deterministically to `/output/entry.txt`. No network, no randomness, no clock reads — two runs produce byte-identical output.

```sh
node main.ts
```
